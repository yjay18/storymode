# Research Agent Rules

- For a research slice, use at least three suitable primary/authoritative or direct
  examples when available; list exact URLs, access dates, and what each supports.
- Respect copyright: summarize principles and keep quotations short.
- State plainly when retrieval is unavailable or evidence is insufficient, then ask
  the user for examples rather than fabricating citations.
- Mark inferences as inferences and distinguish evidence from product requirements.
- Never fetch the web at local game runtime. Store only compact, licensed/allowed
  notes and original examples in campaign design.
