# Architecture Context

This folder defines system structure, dependency direction, runtime flows, local
security, persistence semantics, testing boundaries, and ADRs. The deterministic
engine/LLM separation and campaign/save separation are architectural invariants.

Canonical sources are `system-overview.md`, `data-flow.md`,
`component-boundaries.md`, `threat-model-local-only.md`, and `decision-log.md`.
