# Game Pillars

## 1. World-bound expression

Players may phrase any plausible exploration attempt, but they control their
character's intent—not reality. Creativity comes from combining known entities,
capabilities, relationships, and environmental facts. Unsupported assertions become
a valid search/attempt when possible or an in-world rejection when not.

## 2. Fair, visible mechanics

All consequential uncertainty uses deterministic rules plus secure local dice. The
UI shows raw die, named modifiers, total, DC, and outcome. No story beat, model, or
difficulty mode alters the random draw.

## 3. Coherent authored truth

A generated campaign is validated and published before play. Protected milestones,
world laws, major entities, and factual IDs do not drift. Runtime opportunities can
create routes through that truth, never rewrite it.

## 4. Tactical clarity

Combat is turn-based and button-driven. Skills always apply their valid base effect;
visible effect dice create texture without repeated misses. Armour, mana, statuses,
flee/yield permissions, and turn order are explicit.

## 5. Local ownership

Campaigns, saves, models, and generated assets stay on the player's computer. Saves
are portable and recoverable. No account, telemetry, hosted service, or cloud model
is required.

## v1 play loop

Review/build campaign -> create character and save -> enter area -> inspect/talk/act
in free text -> validate and possibly roll -> commit and narrate -> update frontier ->
prepare or enter combat -> choose bounded actions -> resolve consequences -> save.

## Explicit non-goals

Multiplayer, GM mode, arbitrary mod execution, open-world simulation, passive world
time, real-time combat, procedural rules, voice, cloud sync, and desktop packaging
are not part of the first vertical product.
